# 报告解释

## 结果分类

- `PASS`：机器断言和安全门禁全部通过。
- `FAIL`：已执行且预期与实际不一致。
- `ENV_ERROR`：登录、连接、依赖或环境不可用，不等于业务缺陷。
- `SKIP`：未建模、未人审或不满足执行条件，不计为通过。
- `ABORTED`：安全网检测到环境干扰或未声明变化，本次结果作废。

## 汇总模板

```text
执行范围：<站点、模块、用例范围>
运行目录：<绝对路径>
结果：PASS n / FAIL n / ENV_ERROR n / SKIP n / ABORTED n
关键失败：<用例、预期、实际、证据>
环境问题：<登录/接口/数据库/依赖>
清理状态：<成功/待清理 marker，不包含秘密>
疑似缺陷：<仅列证据充分的候选>
下一步：<修环境、补建模、开发确认或定点复跑>
```

## 表述要求

- 明确区分业务失败与环境失败。
- 引用报告、截图和结构化证据的文件路径。
- 不粘贴秘密、完整 Cookie、认证头或数据库口令。
- 不因总通过率好看而隐藏 SKIP、ENV_ERROR 或清理失败。

# 走单对账执行:从页面走通 → 看接口 → 看数据库 → 打分 → 自检

你负责把测试按**走单对账**流程跑出来并对执行质量负责。核心是一条**因果链**:同一笔被测动作**由页面驱动**,接口是这次点击的副产品,库是它的落库结果,三者指向**同一张单**。打分器(`core/fidelity`)给每条用例 0-100 的保真度 + 审计(`cases/<id>/audit.json`);你要据此自检,**不达标自己补,别报假绿**。

## 铁律(别违背初衷)
1. **走单,不是看结果**。被测写动作必须**页面驱动**(点/填/提交),`act_via` 默认 `ui`。**绝不**用接口直接建单再开页面"看结果"冒充走单——那样 `ui_driven` 维度得 0、审计一眼露馅。只有用例显式 `act_via: api`(接口+库类)才允许接口建单。
2. **接口被动抓,不主动代跑**。页面点击触发的写请求由 `core/uicapture` / prober **在旁录**(`calls.json`),对账就用**这次录到的写请求响应**,不要另开 adapter 主动 call 一个"看起来一样"的请求。
3. **三源同一标记**。页面反馈、被动抓到的写请求、按 `{{marker}}` 查库,三处必须指向**同一张单**;否则 `consistency` 不通过。
4. **证据走 uicapture**。UI 场景一律 `with ui_capture(...)`:视频 + 分步截图 + `calls.json` 路线 + `trace.zip` + `index.html`,落 `workspace/runs/.../<场景>/`。
5. **造数保留**(带 AUTOTEST 标记),作测过的证据,不删。

## 执行流程(每条用例)
1. **定契约**:确认该用例 `act_via`(写/流程类默认 `ui`;纯接口+库类才 `api`)。
2. **走单驱动**:开页面,按 `page_model` 点/填/提交;uicapture/prober 旁录接口与视频。
3. **三源对账**:页面状态/反馈 == 被动抓到的写请求响应 == 按 marker 查库,校验同一单。
4. **看分 + 读审计**:执行器已算好 `fidelity`(score/grade/五维度)写进 `audit.json`;重点看 `ui_triggered` 是否 True、`consistency` 是否通过。
5. **不达标自己补**:分数低于及格线(默认 60)或 `ui_driven=False`——**先自救**(修选择器/补 page_model/换定位策略/查知识库),重跑到达标;实在走不通,在报告里**如实标注**是哪一维度缺、为什么,绝不把"接口+库"冒充三层走单。

## 自主执行契约(不把人拉进执行回路)
- 给定范围(如"测所有 X 场景")就**一口气跑到完**,中途**绝不**停下问"要不要继续"。
- 卡住先**自救三板斧**:①写代码/脚本/skill 绕过;②查知识库 / 源码契约(`core/discovery/srcmap`)/ PRD;③换策略(换登录态、换可复用的既有单、换选择器)。
- **只有**这两种才问人,且**一次问清**:缺凭据(账号/登录)、或业务规则未定义(口径无处可查)。其余一律自己扛到底。

## 收尾自检(强制逐条 YES/NO,仿防走偏)
批次跑完,对照 `audit.json` / 报告逐条核对,每项必须明确 YES/NO:
- **UI 驱动了吗?** `audit.ui_triggered == True`(走单类)。NO → 没走单,去补驱动,别报绿。
- **三源同单吗?** `consistency` 维度通过。NO → 查哪一源不一致,补齐。
- **证据齐吗?** 视频 + 分步截图 + calls + trace 都在。NO → 重跑经 uicapture。
- **分数达标吗?** `fidelity.score >= 及格线`。NO → 定位失分维度,先自救再重跑。
任一 NO 且无法自救 → 报告里**显式标注受阻**(哪维度、为什么),不计通过。

## 门禁(要让"走单却没走"翻红)
默认只打分+标注、不改 verdict(兼容既有基线)。要让声明走单却没走的用例**直接判不达标标红**:
```bash
python run_batch.py --specs workspace/specs_auto --strict-walk
```
或在 `workspace/config/scoring.yaml` 设 `strict_walk: true`。权重/分档/及格线也在该文件调。

## 产出给用户
报告路径 + 一句话:通过/不达标几条、**保真度分布**(各档几条)、审计异常项(声明走单却没走的、三源不一致的),以及造数保留位置。不复述全过程。

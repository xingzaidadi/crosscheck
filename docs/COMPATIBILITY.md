# Crosscheck 兼容矩阵

## 正式支持

|层|范围|状态|
|---|---|---|
|操作系统|Windows 10/11|发布门禁覆盖|
|浏览器|Playwright Chromium|正式支持|
|应用|浏览器访问的企业 Web 系统|正式支持|
|接口|HTTP REST/JSON，Cookie 登录态|正式支持|
|数据库|MySQL 8.x|正式支持；只读查询与独立写账号|
|本地演示|SQLite|仅演示、离线测试|
|认证|简单账密自动登录|正式支持|
|认证|SSO、MFA、验证码|人工完成安全挑战后复用登录态；支持 TTL 和判活，不绕过安全控制|

## 有条件支持

- 动态 SPA、常见 Ant Design/Element/普通 HTML 表单：需要稳定语义标签或录制 page model。
- iframe、Shadow DOM、Canvas、远程桌面页面：必须先 PoC，不能默认承诺。
- PostgreSQL：已有只读表/字段元数据分支，但仍需真实系统、写入和清理验收后才能升级为正式支持；Oracle、SQL Server 需要 workspace 插件扩展。
- GraphQL、SOAP、gRPC、WebSocket、SSE、MQ：没有内置协议执行器；只能新增插件后验收。
- 插件扩展必须实现 `core.plugins` 中的协议/数据库契约，并提供独立的请求、响应、断言、清理和真实系统证据；仅注册类不会自动获得正式支持。

## 明确不支持

- 原生 Android/iOS、小程序、桌面客户端和 Citrix/SAP GUI。
- 性能、容量、渗透、安全漏洞和像素级视觉回归测试。
- 生产环境写入测试。
- 自动绕过验证码、MFA 或企业 SSO 安全控制。
- 在没有业务 oracle、断言和清理契约时自动判断业务正确性。

## 支持声明规则

任何新增数据库、协议、浏览器或客户端只有在插件、负向测试、清理测试和真实环境证据均完成后，才能从“有条件支持”移动到“正式支持”。
